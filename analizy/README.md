# 📂 Katalog Analiz — Projekt TAROT

Ten katalog służy do gromadzenia raportów i analiz od różnych agentów AI, które następnie zostaną poddane syntezie.

## Struktura

```
analizy/
├── README.md                  ← ten plik
├── synteza/                   ← wyniki syntezy wszystkich analiz
│   └── synteza_glowna.md      ← główny dokument syntezy
├── raporty/                   ← surowe raporty od agentów AI
│   ├── agent_01_nazwa.md
│   ├── agent_02_nazwa.md
│   └── ...
└── notatki/                   ← dodatkowe notatki i obserwacje
```

## Instrukcja

1. **Wrzucanie raportów** — Każdy raport od zewnętrznego agenta AI zapisz w katalogu `raporty/` z opisową nazwą pliku.
2. **Format nazwy** — `agent_XX_temat.md` (np. `agent_01_analiza_rynku.md`)
3. **Synteza** — Po zebraniu wszystkich raportów, uruchomimy proces syntezy, który wyciągnie najciekawsze pomysły i koncepcje.
