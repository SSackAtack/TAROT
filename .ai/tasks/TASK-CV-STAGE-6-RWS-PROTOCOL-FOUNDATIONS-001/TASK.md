# Task: stage-6-rws-protocol-foundations

## Description
Integracja protokołu komunikacyjnego WebSocket dla Autotune (etap 1 z podziału PR-F).

Wprowadzenie definicji struktur danych, parsowania i walidacji dla przyszłych komend WebSocket powiązanych z autotuningiem. Zmiany nie mogą wchodzić w interakcję z pętlą główną przetwarzania ani serwerem WebSocket.

## Scope
- `app_cv/tarotvision/tuning_protocol.py`
- `app_cv/tests/test_tuning_protocol.py`
